The app does not show a personal name or a home address.

A profile on the device stores a first name or one initial, an age range, and an animal that is already in the app. Photos stay on the device. There are no ads. Kids never log in.

A grown-up can set a 4-digit PIN on this device. The app stores a digest of the PIN, not the digits. Forgot PIN asks a harder multiplication check, then a new PIN. Replacing the PIN does not delete profiles or progress.

A classroom device stores an avatar and a nickname. It does not store a real first name.

Optional grown-up sign-in uses Firebase Authentication and Cloud Firestore only. The app does not use Firebase Analytics, Crashlytics, or Remote Config. Teacher and admin state (the school, classes, roster, invites, and settings) is stored in Firestore. This device keeps a cache so the screen can open offline. Preview modes use fixtures and ignore that cache.

A class link, after a parent agrees, may sync only this sentence and no other sharing promise:

practice days, active minutes, and session length, as class totals, with no names

That sync does not include first names, photos, or audio. Server copies for a class link are deleted on unlink or account deletion.

Links that leave the app, including Tell a friend and printables, stay behind the grown-up gate.
