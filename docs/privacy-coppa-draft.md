The app does not show a personal name or a home address.

A profile on the device stores a first name or one initial, an age range, and an animal that is already in the app. Photos stay on the device. There are no ads. Kids never log in.

A grown-up PIN is stored as a digest. Recovering it does not wipe progress. A classroom device stores a nickname, not a real first name.

Optional sign-in uses Firebase Authentication and Cloud Firestore only. Class links may sync only: practice days, active minutes, and session length, as class totals, with no names. First names, photos, and audio stay off that sync. Teacher and admin state is stored in Firestore. This note is not shown in the app as a finished notice.
