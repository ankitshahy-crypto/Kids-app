# Easier-to-read font

The "Easier-to-read font" setting in Grown-ups uses Atkinson Hyperlegible
when these two files are in this folder:

- `AtkinsonHyperlegible-Regular.woff2`
- `AtkinsonHyperlegible-Bold.woff2`

Download them from the Braille Institute (free, SIL Open Font License) and
drop them in here, keeping the names exactly as above. Nothing else needs to
change: the app adds the font rules itself and ships the files with the
offline cache. Until the files are here the setting falls back to Verdana,
which is already on iPhones, iPads, Macs, and Windows PCs.
